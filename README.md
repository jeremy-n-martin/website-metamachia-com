# Metamachia MVP

Site statique minimal autour d'un graphe épistémique typé.

Le contenu livré est volontairement réduit à des **objets démo** :

- 4 concepts ;
- 5 relations ;
- 2 parcours d'exemple.

## Lancer en local

```powershell
python -m http.server 8000
```

Ouvrir `http://localhost:8000`.

Aucune compilation. Point d'entrée : `index.html`.

Les données sont dans `assets/epistemic-data.js`. Voir `GUIDE_UTILISATION_METAMACHIA.md` pour les enrichir.
